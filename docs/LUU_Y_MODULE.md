Mỗi người đọc TODO tại file của mình, tự viết test và hướng dẫn. File dùng chung như app.module.ts, types/contracts.ts, config, routes, README, workflows và database phải báo nhóm trước khi sửa. Người sở hữu logic không đồng nghĩa sở hữu mọi file giao diện có gọi logic đó.
